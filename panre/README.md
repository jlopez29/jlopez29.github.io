# ReCert Ready

ReCert Ready is a dependency-free PANRE-LA practice prototype built for this portfolio. It includes:

- 510 original clinical practice questions across all 15 NCCPA blueprint categories
- 450 focused flashcards covering presentation, diagnostic evidence, and management
- Exact blueprint-weighted mixed sets (weights total 100%)
- Adaptive practice that emphasizes lower-performing categories
- Active-recall cards with confidence-based review timing
- A three-minute clinical sprint with combo scoring
- A 25-question mock quarter with five minutes per item
- Local-only session history, category mastery, study streaks, and recommendations

## Run locally

Serve the repository root with any static server, then open `/panre/`. No build or package install is required.

## Content note

This is independent educational practice, not an NCCPA product and not medical advice. The allocation follows the [NCCPA PANRE/PANRE-LA content blueprint](https://www.nccpa.net/resources/panre-panre-la-content-blueprint/) effective January 2023. The expanded curriculum links to 15 specialty-society reference hubs. It is AI-authored and must receive qualified clinician editorial review before high-stakes or commercial use.
