# Premium slot presentation

The supplied raster pack is used by the single shared `slot_presentation.gd` renderer in public play, sponsored events and the Back Room. The five canonical symbols retain their original numeric IDs and paytables; alternate supplied symbols are imported artwork only.

Both cabinet layers use their native aspect ratio (1080/800 landscape, 780/1000 portrait), with a normalized reel window of `(0.10, 0.23, 0.80, 0.48)`. The base supplies the cabinet and result-panel borders. The transparent glass supplies only the two reel-divider rails; the outer bezel comes from the base alone. Runtime payline markers sit inside the reel window, clear of the trim. Do not draw a second border over these layers.

The cabinet contains exactly three real Godot buttons: BET advances the wager and wraps from the affordable machine maximum to its minimum; LINES cycles 1 / 3 / 5; the circular SPIN button retains safe SKIP behavior. Portrait and desktop use a lower control deck, while short landscape uses a side deck. Neutral cabinet material extends to enclose the controls in one continuous shell; illustrated details and outer caps retain their native proportions. All targets are at least 44 pixels in each dimension. Results have a dedicated dark-glass plaque immediately below the reels, with limits and LAST WIN in the original compact meter strip.

Some supplied files contain source-atlas remnants. `SYMBOL_REGIONS` excludes neighboring art from BAR/bell and the stray strip above seven, while preserving symbol proportions. Coin/sparkle regions select single complete particles and exclude source rules. The unusable glow sheet was removed because it contained baked heading text and a truncated ring; the renderer uses a small procedural halo instead. The large jackpot burst is drawn behind symbols and particles are clipped to the reel window so financial text and controls remain clear. The original PNG bytes are preserved.

PNG imports enable mipmaps for clean downsampling. Cached textures and a bounded deterministic particle pool avoid new gambling RNG calls or per-frame image processing. Motion preferences suppress bounce, trails, flashes, particles and animated cabinet lighting. Full exports use `export_web.py`. The installation manifest and package reference composites were removed after integration. Alternate symbols and the optional jackpot flash remain as reserved artwork; they are not part of the active paytable or effect sequence.
